The structural pieces of Mush/www/img/design (CC BY-NC-SA 4.0, Motion Twin), assembled with plain CSS from web/src/designKit/designKit.css. The archive has no original stylesheet, so assemblies are inferred from file names and sizes: guess marks the ones where the fit or placement is a guess, in game marks art the game already uses. Each story lists its source files with natural sizes; non-PNG files are only included where they complete a PNG set. Icons, logos, packs and illustrations are left out (listed at the bottom). Nothing is scaled.

CSS kit

The same pieces drawn with CSS only (Mush/derived/kit.css), so they can be any size. Each story shows the PNG original and the CSS version at the original size (each pair shares a data-pair name), then the CSS version at other sizes. Left out: the "NERON" letters baked into barinprogress.

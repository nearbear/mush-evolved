Changes: some third-party logos and award badges were removed (see `docs/assets/mush-assets.md`). The web
client keys out the solid background color of the character sprites at runtime;
the files themselves are unmodified.

`derived/` holds files made from this material: `ship-art.json`, built from
`clients/iso/xml/tiles.xml`; `ship-map.json`, the rooms, first converted from
`clients/iso/gfx/ShipMap.png` and edited by hand since; `ship-rooms.json`, read
from the map; and `ship-plan.json`, decoded from the ship plan serialized in
`src/common/data/Map.hx` (the generated ones by `npm run ship-layout`). They are
adaptations and are also licensed CC BY-NC-SA 4.0. `derived/pages/*.png` are
`clients/iso/gfx/BigFill.png` and `BigFill2.png` repacked by the same command
into images of at most 4096 px a side (the sprites are copied unchanged, some
animation strips wrapped onto two rows), so phone GPUs can load them.

`package.json` is project metadata, not part of the upstream material; it lets
the game's code import `derived/` by package name.

This project is not affiliated with or endorsed by Motion Twin. "Mush" is used
only to credit the source.

`derived/pip-bar/*.svg` are generated from the pixels of the AP bar frame
`www/img/design/pabar.png`, rotated to run horizontally and split into pieces
so any slot count works. They are adaptations and are also licensed CC BY-NC-SA 4.0.

`derived/kit.css` redraws pieces of `www/img/design` (progress bars, tabs, item
slots, the tooltip and popup frames, box2, the main content panel) in CSS, with
colours sampled from the PNGs, so they can be drawn at any size. It is an
adaptation and is also licensed CC BY-NC-SA 4.0.

The web client's star field (`web/src/iso/starfield.ts`) is generated by code,
not copied art, but takes its colors and style from `clients/iso/gfx/bg.png`.

`derived/techno-box.png` is `www/img/design/xp_counter.png` edited by hand into a
closed box (the left end cap mirrored onto the right, the fade removed). It is
an adaptation and is also licensed CC BY-NC-SA 4.0.

`derived/items/` holds item icons made by hand for this project from the
original item icons (the blue slot tile and, where noted, parts of other
icons). They are adaptations and are also licensed CC BY-NC-SA 4.0. Each file:

- `super_kube.jpg`: drawn on the blue slot tile (`www/img/icons/items/empty.jpg`).

`derived/webp/*.webp` are lossless WebP re-encodings of the 7 largest PNG sprite
sheets (`derived/pages/BigFill-0.png`, `derived/pages/BigFill2-0.png`,
`www/img/art/char.png`, and `clients/iso/gfx/{gfx_01,MidFill,MidFill2,fx}.png`),
generated by `npm run webp-sheets` to reduce download size while keeping visible
pixels unchanged. They are adaptations and are also licensed CC BY-NC-SA 4.0.

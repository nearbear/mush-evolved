# Hand-made item icons

Item icons made for this project, built on the original's art (for example drawn
on the blue slot tile, `www/img/icons/items/empty.jpg`). They are adaptations of
Motion Twin's Mush and licensed CC BY-NC-SA 4.0, like the rest of `Mush/` (see
`../../ATTRIBUTION.md`).

- Match the originals: 50x50, `.jpg` or `.png`, on the blue tile.
- Name the file after the item type id (e.g. `space_wrench.png` for item type
  `space_wrench`). `web/src/art/assets.ts` picks up every file here; a file with
  the same name as an original icon replaces it.
- Add a line to `../../ATTRIBUTION.md` saying what each icon was made from.

# Code map: shared

Other packages import from `@mush2/shared` (`shared/src/index.ts`, the barrel). Inside `shared`, import types from `types.ts`.

## Engine

- `rules.ts`: `createGame`, `newPlayer` and `startInventory` (also used by `joinShip`), `applyAction` (at once, no timing), `performAction` (its mutating core), `legalActions`, `viewFor` (without log ids), `seatViewFor` (with them, a `SeatView`, replay only; Biome forbids it in `server/src`), `affordable` and `legalIn` (read a view's `actions`), `dayOf` (re-exported from `helpers.ts`), `setCheat`, `setActopiCheat`; private `advanceCycle` and `grantCarePoints`. `viewFor` is the single place hidden info is stripped.
- `actions.ts`: the action registry (`ACTIONS`), `ActionDef` / `ActionCost`, and the `Action` union, derived from the registry (`types.ts` re-exports it). `actionVisibility` and `actionInTerminal` read fixed per-type flags. A new action is a file in `actions/` registered here.
- `actions/action.ts`: the `Action` base class (`getCandidates`, `validate`, `getCost`, `apply`, optional `getSuccessChance` and `fail`; `check` is `validate` then the price, never overridden). The constructor takes a check per field (`Fields`, `isString`, `isBoolean`), which `parse` uses to rebuild an action from untrusted client input; `terminal` marks actions done in a terminal's window.
- `actions/capsule.ts`: `carriedCapsule` and `combustionLevel`, for the fuel and oxygen actions.
- `blueprints.ts`: `BLUEPRINTS` recipes (ingredients and resulting equipment) and the `blueprint` item type name.
- `actions/<type>.ts`: one class per action: `reset_skills`, `mass_mouldering` (the Mush skill Mass Mouldering), `give_disease` (the Mush skill Bacteriophilia), `nightmare` (the Mush skill Nightmarish: curses a human with Bad Luck), `demoralize` (the Mush skill Demoralizer, `disheartening_contact`), `accommodate` (+ `accept_accommodation`, `stop_accommodation`), `access`, `bond`, `build`, `caress` (Caress Schrödinger), `mush_caress` (Infectious Caress on Schrödinger), `check_combustion`, `consume`, `cook`, `express_cook`, `hyperfreeze`, `water`, `treat`, `sow`, `graft` (a Botanist grafts a held alien fruit onto a plant: a hybrid, #438), `dismantle`, `dispense`, `play_arcade` (the Dynarcade), `listen_jukebox` and `check_jukebox` (the jukebox), `examine`, `consume_spore` (the Mush skill Phagocytosis), `tube_transfer` (the pneumatic tube), `extract_spore`, `heal`, `use_bandage` (a consumable heal), `remove_spore` (the Spore Sucker), `install`, `jettison`, `lie_down` (+ `get_up`), `uninstall`, `move`, `pick_skill`, `apprenticeship` (the Apprentice skill), `become_genius` (the Genius skill), `ceasefire` (the Diplomat skill), `read_book`, `tear` (destroys a document, #394), `print_list` (THE List at the tabulator, #266), `snoop` (the Scrapper's Snoop), `check_spores` (the MycoScan's spore check), `warp_to_planet` (development-only, the `easyTravel` cheat), `project`, `repair_pilgred`, `return_to_sol`, `contact_sol`, `decode_rebel`, `contact_xyloph`, `update_neron`, `contact_signal` (answers a signal's hail;
